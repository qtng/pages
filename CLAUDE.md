# qtng/pages

The landing pages of the Chunom site for search engines and old links, published from `docs/` at `chunom.org/pages/`. Most of `docs/` is generated, do not edit it by hand.
All instructions (the four repositories and how they belong together, URL rules, translation, and everything about this repository) are in the private repository `qtng/chunom-private`, file `CLAUDE.md`, section "The public repositories"; attach it with `add_repo` when a session starts here. Nothing technical is written in this public file.
Always: Root-relative paths; the generator is `tools/pages/generate.py` of the private repository.
