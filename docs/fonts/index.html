Fonts for Chu Nom

Free CJKV Fonts with Chu Nom coverage

For a full Chu Nom coverage, it is recommended to install "HanaMin" plus one of the other fonts. For cursive style characters like those on this website install FZKaiT.

  • HanaMinA + HanaMinB (Hanazono Font)
  • Nom Na Tong (serif)
  • Han Nom Gothic (sans-serif)
  • Han Nom Kai (khải-thư / regular)
  • FZKaiT-Extended + FZKaiT-Extended(SIP) (click on 主力HTTP下载)
  • Han Nom A + Han Nom B
  • MingLiU + MingLiU-ExtB (included in Windows Vista and Windows 7)
  • STXiHei or "Heiti TC" (included on MacOS)

On Windows XP

For Windows XP to display Chu Nom characters in Unicode Extension B and C a font must be installed. You can find free CJKV fonts on the list above. To also display Unicode Extension C characters the only available font is HanaMinA + HanaMinB.

On Windows Vista and Windows 7

Windows Vista and Windows 7 come with MingLiU and MingLiU-ExtB which have a good coverage of Chu Nom characters in Unicode Extension A and B. Installation of alternative CJKV fonts is optional, see list above. However, to also display Unicode Extension C characters please install HanaMinA + HanaMinB.

Apple Mac OS

Apple Systems provide STXiHei and Heiti TC, both include many Chu Nom characters. For a better coverage, please install alternative free CJKV fonts from the list above. To also display Unicode Extension C characters the only available font is HanaMinA + HanaMinB.
